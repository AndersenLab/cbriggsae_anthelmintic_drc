# **tables** 
This directory contains the supplementary tables 
- `CNV_genesOfInterest.tsv`
Orthogroup table for genes of interest for each strain
- `Table_1.csv`
Effective concentrations (ECs) for all drugs
- `Table_2.csv`
Broad-sense and narrow-sense heritability calculations for all drugs
- `Table_3.csv`
Slope calculations for all drug dose response curves
- `Table_4.csv`
EC comparisons between all strains within each drug
- `Table_5.csv`
Slope comparisons between all strains within each drug
- `Table_6.csv`
Heritability calculations at effective concentration
- `Table_7.csv`
Broad-sense and narrow-sense heritability calculations on filtered data set (only wells greater than or equal to 5)
